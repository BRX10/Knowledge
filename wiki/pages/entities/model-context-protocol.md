# Model Context Protocol

[[dynamic-context]] requires standard access to knowledge bases. Open protocols such as the Model Context Protocol let any agent query any base in the same way, rather than through proprietary connectors ([[portability]]). In [[fig-4-multi-base]], MCP is the common access layer that serves people and agents by use case.
